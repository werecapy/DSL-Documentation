# Markdown
Wow! The text you're reading right now was orignially written in markdown. Isn't that cool? It is used for formatting text. Markdown is a relatively lightweight language and can be seen in READMEs, PDFs, LaTeX, Word documents, and more. This language can handle code snippets, math equations, checklists, bullet points, numbered lists and tables.
