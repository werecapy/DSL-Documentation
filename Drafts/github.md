# Github
Github is a type of version control for youer projects. Screw up way down the line? Github has you covered. You can go back in time and recover a useable version of your project. 

## Terms to know

| Term | Definition 
| -------- | -------- | 
| Push  | Saving your data to a LOCAL or REMOTE repository |
| Pull    | Brings latest changes to your working files from the remote repostiory.     | 
| Commit | A snap shot of your files at that point in time. Does not get sent anywhere. Make sure to add all the files you want to the snapshot and record what you did in the commit message for easy tracking.
| Fetch | Downloads all changes to your files from the repository- DOES NOT CHANGE FILES. Use this to inspect changes before you merge. 
|Merge | Combines two seperate branches or changes together.
